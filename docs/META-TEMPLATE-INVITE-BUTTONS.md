# תבנית "הזמנה עם כפתורי אישור" — נוסח להגשה במטא

**למה:** אצל איילת, ההזמנה עם הקישור הביאה 10 תשובות ביומיים. התזכורת עם כפתורים
הביאה 97 ביום אחד. לחיצה בתוך הוואטסאפ קלה יותר מכניסה לאתר.
ההזמנה המלאה עם האנימציה נשארת, ככפתור רביעי.

**למי:** רק לזוגות חדשים, וכל חתונה מופעלת בנפרד. לא לחתונות שכבר יצאה בהן הזמנה.

| שדה | ערך |
|---|---|
| **Name** | `wedding_invitation_buttons_v1` |
| **Category** | Marketing (מטא תסווג ככה בכל מקרה, כמו את `wedding_invitation_v3`) |
| **Language** | עברית (Hebrew) |
| **Header** | Image (תמונת ההזמנה של הזוג, כמו היום) |

**Body:**

```
💍 משפחה וחברים יקרים!

בעזרת ה׳ *{{1}}* מתחתנים! 🤍
והם שמחים להזמין אתכם לחגוג איתם:

🗓 {{2}}
📍 {{3}}
🥂 {{4}}

נשמח שתאשרו הגעה בלחיצה על אחד הכפתורים למטה 👇
```

**Sample values:**

| | |
|---|---|
| `{{1}}` | ירון פטיניו ואיילת דוד |
| `{{2}}` | יום רביעי, 14 באוקטובר 2026 · ג׳ חשוון תשפ״ז |
| `{{3}}` | אולמי פאלאסיו, אופקים - אזור התעשייה, הבנאים 23 |
| `{{4}}` | קבלת פנים 18:15 \| חופה וקידושין 19:15 |

**Buttons — בסדר הזה בדיוק:**

| # | סוג | טקסט |
|---|---|---|
| 1 | Quick Reply | `כן, אגיע` |
| 2 | Quick Reply | `לא אגיע` |
| 3 | Quick Reply | `עדיין לא יודע/ת` |
| 4 | Visit website (Dynamic URL) | `לצפייה בהזמנה`. **אותה כתובת בדיוק כמו בכפתור של `wedding_invitation_v3`**, עם `{{1}}` בסוף |

⚠ **הטקסטים של שלושת הכפתורים חייבים להיות זהים לאלה שבטבלה, כולל הפסיק והלוכסן.**
לחיצה חוזרת אלינו כטקסט של הכפתור, והקוד מזהה בדיוק את המחרוזות האלה
(`INVITE_BUTTON_LABELS` ב-`src/lib/whatsapp.ts`).

---

## אחרי שמטא מאשרת

1. ב-Vercel (Production) מוסיפים `WHATSAPP_TEMPLATE_INVITE_BUTTONS` = `wedding_invitation_buttons_v1`.
2. מוסיפים את ה-id של **החתונה הראשונה** ל-`INVITE_BUTTONS_EVENTS`. אפשר כמה, מופרדים בפסיקים.
3. Redeploy.
4. **3 ימים בלי אי-הסכמות**, ורק אז מוסיפים את החתונה הבאה.

כל עוד אחד מהשניים חסר, כל החתונות ממשיכות לקבל את ההזמנה הרגילה עם הקישור.
זו ברירת המחדל, ולא צריך לעשות כלום.

## מה קורה כשאורח לוחץ

- **כן, אגיע**: נרשם כמגיע, ונשאל "כמה אתם מגיעים?". זו אותה זרימה כמו בתזכורת היום.
- **לא אגיע**: "רק לוודא — לא תוכלו להגיע?". גם זה כמו היום.
- **עדיין לא יודע/ת**: לא נרשם. מקבל "בסדר גמור 🤍 עוד לא רשמנו אתכם — נזכיר לכם קרוב לחתונה",
  ויקבל את התזכורות הרגילות בשבועיים האחרונים.
- **לצפייה בהזמנה**: ההזמנה המלאה באתר, כמו היום.
